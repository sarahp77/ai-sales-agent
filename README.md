# Autonomous Sales Agent (LangGraph + Streamlit)

A conversational AI assistant designed for product recommendation and dynamic inventory querying. The project implements a cyclic state graph using **LangGraph** to handle multi-turn dialog, execute tool calls against a local catalog, and maintain conversational boundaries through system-level guardrails.

---

## Overview & Architecture

The agent operates as a state machine where incoming messages update a shared conversation state. Based on user intent, the model either invokes internal tools to inspect inventory or responds directly.
```text
+-------------------+
|    User Input     |
+---------+---------+
|
v
+-------------------+
+----> |    Model Node     |
|      |   (GPT-4o-mini)   |
|      +---------+---------+
|                |
|         [Tool Needed?]
|          /           \
|       (Yes)          (No)
|        /               \
|       v                 v
|  +---------+      +-----------+
+--+ Tool:   |      | Respond   | --> END
   | Catalog |      | to User   |
   +---------+      +-----------+

```
### Core Design Decisions:
- **State Management:** Uses LangGraph's `StateGraph` with message history appends (`add_messages`).
- **Tool Calling:** Intercepts `tool_calls` generated by the model to query product records (JSON) and injects results back into the state before generating the final reply.
- **Domain Scoping:** Configured with explicit fallback instructions to ignore off-topic queries and focus exclusively on product discovery and sales support.

## Setup & Running Locally

### 1. Clone the repository
```bash
git clone https://github.com/sarahp77/ai-sales-agent.git
cd ai-sales-agent
```

### 2. Set up environment
```bash
python -m venv venv
```

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

### 3. Install packages
```bash
pip install -r requirements.txt
```

### 4. Add API Key
Create a `.env` file in the root directory:
```bash
OPENAI_API_KEY=your_openai_api_key_here
```

### 5. Launch the UI
```bash
streamlit run app.py
```
